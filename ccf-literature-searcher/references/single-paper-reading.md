# Reading One Paper

Start with the reader's question. Identify the version available and cite the section, equation, table or appendix that answers it. If only the abstract is available, describe its stated claim and identify the missing passage needed for the question.

- **Explain a method.** Follow one input through the decisive operation to the output. Give the shapes, units or assumptions that matter. If an equation is hard to interpret, calculate a small example by hand and label the numbers as illustrative. Check whether the example satisfies the paper's assumptions.
- **Interpret a result.** Read the caption and experimental setup together. Record the comparator, metric direction, evaluation split, sample size and meaning of error bars where reported. If a table and its appendix use different settings, give both locations and explain which comparison each supports.
- **Attribute a gain.** Look for the comparison that actually changes the named component under matched conditions. A full-model result supports the joint configuration. If a component was never isolated, its individual effect remains undetermined.

Answer the question at the requested depth. Broader literature searches, replication plans and manuscript reviews are separate requests.
