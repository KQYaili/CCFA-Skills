# Tracing a claim to its primary source

Separate factual assertions that need different evidence, even when they share one citation. For each disputed assertion, locate the cited version and the smallest passage that can settle it, such as an equation, table row, caption or methods paragraph. A review can establish what its authors concluded in their synthesis. For a number attributed to an underlying trial, follow its citation to that trial.

Match the wording to the observation. Check the population, comparison, unit, denominator and direction where they affect the claim. For example, if Table 2 reports an error rate falling from 20% to 18% on one dataset, it supports a two-percentage-point reduction there. A draft attributing a ten-percentage-point reduction across datasets to that table has both a unit error and a scope error.

If a correction, retraction or later version is material, inspect the dated notice and the affected passage. Identify which claim or value changed and revisit findings that relied on it. If the notice is unavailable, report the version inspected and what remains unknown about the update. For a publication-status check, use [bibliographic integrity signals](bibliographic-integrity-signals.md).

Report the supporting or conflicting passage and the smallest warranted correction in the existing audit. If only the bibliographic record was available, state which details were confirmed and which content could not be assessed. A search handoff uses the existing [five citation verdicts](../../ccf-literature-searcher/references/citation-verdict-protocol.md). Claim audits retain the support labels in [the auditor workflow](../SKILL.md).
